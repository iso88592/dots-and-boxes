Dots and Boxes

Creating something great

You are now entering a land where the magic happens. Note, that none of your code will be used for training AI. This environment is yours alone. This is ephemeral. This repo will be available until the game lasts. When your design container stops, all your work will be gone. Forever. You can still keep your local repository and use it as-is, wherever you'd like to.

Here is what you'll need to progress:

Access to my container network

If you can read this from your own machine, congrats - you've breached the firewall and made it inside. You're in.

A working ssh command

You likely already have SSH installed. Go on, fire up a terminal and check your ssh command!

A working SSH private-public key pair

Now this is the hard part. First of all, check your home directory for a hidden directory called .ssh and if you see a file ending with .pub, you're most likely good to go. Remember this file because you'll need it down below.

If you don't have an SSH key pair, you need to generate one. Try this: ssh-keygen -t ecdsa -b 521

A working git command

If you are using Windows, or you just like to download random stuff from the internet, git yourself a version control system!

If you are using a package manager, consult it for installing the package git

An IDE of some kind to make C# code

VS Code is fine for this task, but you can also use Rider or Visual Studio if you must. Or you can just go neovim.

Optionally you can get a local version of .net core 9.0 working on your machine. All compilation will go through the system, but you can still use a local version for testing your changes before submitting.

Once you’ve checked all the boxes (in your head, because I'm not that good in html to make checkboxes, duh!), scroll down and submit your stuff like the hacker you are.

Your PUBLIC SSH key

Currently, you can only add one public key per host. // TODO

By submitting your public SSH key, you are consenting to have fun.

Never share your private key, especially not over untrusted networks. Especially not over HTTP. You have been warned!

Way to go!

Now you just need to clone this repository:
git clone ssh://root@:/root/dots-and-boxes.git ./dots-and-boxes

You can also send this command to your teammates!

If you have finished, you can go back to the dashboard.
